# AGENTS.md

Dart CLI (SDK ^3.5.0): weekly promo scraper + Telegram bot for Indonesian F&B/Lifestyle deals. Single package, no monorepo.

## Commands

```bash
dart pub get
dart run build_runner build --delete-conflicting-outputs   # REQUIRED, see codegen below
dart analyze                                                # verification: analyze + compile
dart run bin/harness.dart                                   # weekly scrape (see "No tests" warning)
dart run bin/bot_listener.dart                              # on-demand bot (long-running process)
dart compile exe bin/harness.dart -o harness_promo          # AOT binaries for deployment
dart compile exe bin/bot_listener.dart -o bot_listener
```

## Codegen is required to compile

`lib/flows/promo_schema.g.dart` is generated by `schemantic_builder` from the `@Schema()` classes in `lib/flows/promo_schema.dart`. The project does not compile without it. **Re-run `build_runner` after every edit to `promo_schema.dart`.**

## No tests, no CI, runs have live side effects

There is no `test/` directory and no CI. Executing either entry point calls real paid/limited APIs (Gemini, SerpApi) **and sends real messages to the configured Telegram chat**. Do not "test-run" the app to verify a change — verify with `dart analyze` and a successful `dart compile exe` instead. Ask the user before any live run.

## Hard architectural constraint: two-phase generation

In `lib/flows/promo_flow.dart`, extraction is deliberately split into TWO `generate()` calls: phase 1 with `toolNames: ['searchPromo']` (tool calling), phase 2 with only `outputSchema`. The Gemini API rejects combining tool calling with structured output in one request ("Function calling with a response mime type: 'application/json' is unsupported"). Do not merge them.

## Environment / runtime quirks

- `.env` (copy from `.env.example`) is loaded **relative to the working directory** — run binaries from the folder containing `.env` (this is why the crontab line `cd`s first). Required keys: `GEMINI_API_KEY`, `SERPAPI_KEY`, `TG_BOT_TOKEN`, `TG_CHAT_ID`.
- `ENABLE_BUZZ_CHECK` / `ENABLE_LINK_VALIDATION` toggle the two optional per-promo extra passes (each costs SerpApi quota).
- Deployment target is a 2GB RAM Armbian STB via the AOT binaries above — keep dependencies and memory footprint light; don't assume `dart run` is available there.

## Conventions

- Code, comments, and Gemini prompts are in English, but **user-facing content is intentionally in Bahasa Indonesia** (promo text, Telegram messages, schema descriptions, search queries). Do not translate Indonesian strings to English.
- `lints` is in dev_dependencies but there is no `analysis_options.yaml` — `dart analyze` runs with default rules.
- README.md is unusually detailed: sections 8–10 explain *why* the architecture is this way (SerpApi-as-tool rationale, buzz-signal cost tradeoffs, link-validation false-negative handling). Read it before changing extraction, buzz, or link-validation logic.
